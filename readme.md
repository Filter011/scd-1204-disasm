# CD Sonic The Hedgehog (Dec 4th, 1992 Prototype) Split Disassembly
## Date of Prototype: December 4, 1992 21:34:01
A split disassembly of CD Sonic The Hedgehog (Dec 4th, 1992 Prototype) for the Mega CD add-on of the Sega Mega Drive. This prototype of Sonic The Hedgehog CD was released as a part of [Sonic Month 2019](https://hiddenpalace.org/Sonic_Month_2019) on October 26th after a community fundraiser.
# About the Prototype
This prototype of Sonic The Hedgehog CD was featured at the Yuusei Sega World (遊星セガワールド) event held in Ryōgoku Kokugikan (両国国技館), Tokyo, Japan on [December 6th, 1992](https://segaretro.org/index.php?title=File:SegaForce_UK_15.pdf&page=6).
